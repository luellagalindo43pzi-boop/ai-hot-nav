关于本站

AI热榜导航聚合 2457 个 AI 相关站点：人工精选 302 项（AI日报 / 工具导航 / 学术前沿 / 政策资讯）+ GitHub Search API 收录的 2154 个非 fork、非归档的高星 AI 开源项目（累计 3200 万+ Stars，数据快照 2026-11-23）。

排序方法论：精选站点采用编辑评估的热度 / 质量双分制（0–100）；GitHub 项目热度 = 20 × log₁₀(Stars) 归一化，质量分综合 Stars、Forks、近期活跃度（pushed_at）、描述与 License 完整度；综合分 = 热度 × 0.65 + 质量 × 0.35。
自动化：engine/ 目录内置 Python 抓取引擎（34 个 RSS 信源、去重、LLM 审核候选站点）与 AI 日报 生成器（默认 mosi.cn · Nex N2.6），GitHub Actions 每 6 小时自动重抓并提交更新。
